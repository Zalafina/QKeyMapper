# QKeyMapper 手册维护

维护仓库内的 `readme/manual/`，生成一个可随release分发的离线HTML。先遵守仓库AGENTS及qkeymapper-workflow；不依赖旧会话、历史out目录或本机安装路径。

## 开始与范围

1. 核对分支、HEAD及相关工作区差异，保留已有编辑。阅读 `readme/manual/README.md`、`coverage.md`，必要时查对应产品入口、调用、保存／取消与运行路径。旧参考文档是线索，当前源码与实际界面是依据。
2. 明确本次修订的章节、配图、重要限制与验证范围；小修订直接采用最小闭环，不默认重做全册或产品门禁。多阶段任务在每个已约定Review点暂停。
3. 手册独立版本、状态、软件核对基线及日期由build.py集中维护。软件升级不自动升级手册；未核对的后续版本不写成已兼容。

## 内容与视觉契约

- 常用操作按用途、入口、步骤、预期结果、限制与相关功能编写；给可照做示例。知识只保留一个主要说明位置，其他章节链接引用；速查表中的名称／格式有对应教程时直接链接，普通键不制造空泛链接。保留既有稳定ID，新增section提供唯一ID和检索别称。
- 解释方向始终为“自己实际按什么 → 希望软件收到什么”。保留默认停止键L-Ctrl+F6及实际配置优先、停止后勿反复按的提醒。
- 明确添加／更新／开始不等于保存。手动切换或自动匹配载入其他配置会丢失未保存内容；按当前源码区分内存变化、即时写入、应用检查点和保存设定。
- 保留Interception不折叠的红色严重风险、固定USB接口与编号限制、电源建议及不保证恢复的边界。SDL2读取物理手柄不等于屏蔽物理输入；不要把配置图写成真实硬件效果。
- 沿用深浅阅读主题、正文／目录17px与辅助文字至少16px，用颜色和字重区分层级；静态标签和功能按钮保持区别。软件配图统一中文、深色、默认比例、2560×1440／100%；仅主题教学允许深浅对照。
- 截图必须来自实际窗口；审阅隐私、文字可读性及内部裁剪。演示配置／窗口明确标注，不伪造游戏或设备连接。裁切保留原像素；原图留out，审核后的PNG放images，资源内嵌不增加发布依赖。
- 用户正文只保留操作、例子、前置条件和有用限制；阶段、截图工具／来源批次、验证过程与交接细节放维护说明或会话，不写进教程。代码名称链接在两种主题下使用链接色和常显下划线，与不可点击代码区分；快捷键提示明确写出用途。
- 保留速查链接代码旁的独立复制入口，不用点击链接来承担复制；并列写法分开复制，保留名称内的斜线、中文及特殊符号。剪贴板不可用时提供纯文本手动复制回退；检查工具用隔离接口验证请求内容，不覆盖用户剪贴板。
- 驱动、外部工具和系统兼容说明按需查上游可靠来源；区分用户报告、推测、源码预期和实测，不写“永久杜绝／100%安全”等保证。

## 生成与检查

正文维护与生成仅需Python 3.9+标准库：`python readme/manual/build.py`。可加 `--output` 指定文件；默认生成 `out/user_manual/release/QKeyMapper使用手册.html`。更新源文件，不手改成品。

- 正文／图片修订：生成器检查ID、链接及内嵌资源；阅读新增说明，审阅相关PNG，浏览器检查受影响章节及代表搜索词。
- 导航／主题／脚本修订：加深浅主题、键盘、图片放大、窄窗口及相关状态回归；涉及历史导航时核对跳转后“返回”恢复原阅读位置、连续跳转及直接打开的边界。调用方法见[工具说明](references/tools.md)。
- 需要新产品配图才构建观察助手；其入口从当前main.cpp派生，只改忽略目录中的副本。先阅读工具说明的安全边界。助手／截图工具变化时完成相应构建、行为及小型自检；不自动展开Qt5、全量静态或ASan。
- 缺少工具或私有桌面捕获失败时报告具体缺口；不自动安装依赖、不切换到Default，不把未执行检查写为通过。

## 交付

1. 给出out中的预览HTML、简短变更清单、实际检查与未覆盖项，标明本地开发检查点或独立提交切点。交付时明确提示：“审阅通过后，请批准更新readme/QKeyMapper使用手册.html并本地提交；批准后我会直接执行，不推送。”已有明确授权时按其范围执行，不重复请求批准。
2. 用户明确批准更新发布文件及本地提交后，用`python readme/manual/build.py --output readme/QKeyMapper使用手册.html`生成仓库发布副本，核对其版本与已批准的维护源一致。不要只复制过期预览或手改生成HTML。
3. 显式暂存本次相关维护源、审核资源、必要技能更新及发布HTML，检查暂存范围后自动创建一个本地commit，报告commit和工作区状态；保留无关修改，不推送。仅确认内容正确、要求继续编写或调用技能，不等于上述提交授权。

遵守其他约定的Review停点。发布只需HTML；EXE、DLL、INI、构建目录、日志和原始捕获不得混入发布或技能提交。
