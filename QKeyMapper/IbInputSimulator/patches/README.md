# Logitech 报告安全修正：独立评审

设计与进度仅维护在 [唯一主计划](../../../handoff/ibinput-simulator/qkeymapper_ibinputsimulator_integration_plan.md)。本页说明固定补丁及已执行的定向证据，不维护阶段进度。

基准：IbInputSimulator 0aba4f4f2b2053f106cee4c3be0a6201d76ca585。补丁只改 Simulator/include/IbInputSimulator/SendTypes/Logitech.hpp，不改公共头文件、导出函数、调用约定或驱动 IOCTL／报告结构。

| 问题 | 修正与影响 |
|---|---|
| 按住鼠标后移动／滚轮会重新生成零按钮报告，其他按钮也可能被抬起 | 同一后端保留按钮位，每个拆分报告携带当前按钮状态，UP 只清除对应按钮 |
| 大位移中间报告及加速度补偿报告失败仍可能返回成功 | 每包检查结果，首次失败立即返回失败；不重发、不转其他后端；拆包计算避免 abs(LONG_MIN) 溢出 |
| 滚轮只看正负，丢失多格幅度 | 整格垂直滚轮逐格发送；不支持的水平滚轮、非整格或 X 按钮与滚轮混合事件明确失败 |
| 重复 DOWN 可能占用额外键槽，第七个键可能虚报成功 | 重复 DOWN 不新增槽，六个普通键满后明确拒绝；UP 清除对应槽，无效 VK／不支持的扫描码或 Unicode 明确拒绝 |
| G HUB 虚拟鼠标激活失败仍返回成功 | 传播失败并关闭本次句柄；句柄初始化且重复销毁安全 |

## 无驱动验证

命令：

~~~powershell
python scripts/build_ibinput_dependency.py --arch x64 --tests
~~~

固定来源原版 DLL 在本机 MSVC 19.44.35222.0／SDK 10.0.19041.0／CMake 3.28.6 下重建成功，原生退出 0；完成 DLL／导入库 PE 检查。补丁测试直接编译原始正式内部头文件，设备目录查询、打开、关闭及 DeviceIoControl 全部使用记录替身，不初始化真实驱动或发送输入。

## 剩余风险及建议

- 上述结果仅证明报告和错误传播的软件契约，不证明厂商驱动、目标应用接收、拖拽或真实故障释放。
- 同步 DeviceIoControl 仍可能阻塞。部分失败时原设备状态可能未知；产品必须停止、尝试在同一后端释放并保留不完整结果，不能用另一个后端补偿。
- 不改变原加速度算法或绝对坐标换算；这些路径仍需独立验证。Razer 不在本补丁内。
- 建议批准补丁进入配套 x64／x86 DLL 重建与分阶段验证；批准不代表所有能力开放或完整验收通过。
- 准确的评审决定、正式依赖是否已替换及能力开放状态以唯一主计划为准。

许可证沿用固定上游 MIT，完整许可见相邻 licenses/。RapidJSON 许可还列有 BSD 的 msinttypes 条款和未使用的 JSON_checker 条款；不引入或分发 bin/jsonchecker。

## 补充独立评审：0002 参数返回边界

编译器在未修改上游报告两处 C4715：USB VK 查询及移动模式分支并非所有路径都有返回值。0002 只在 USB 查询尾部补充返回 0，并在 IbSendMouseMove 入口拒绝非法 MoveMode；正常参数及公共 API／ABI 不变，不新增系统调用。

最小替身测试证明：上游非法模式会进入发送替身（exit 2），修正后非法模式不进入发送，合法相对移动仍调用一次（exit 0）。x64 配套修正版 DLL 及报告／参数测试已重建通过，编译日志未检出警告；x86 已完成相同对照及配套重建，两架构均通过。用户已分别批准 0001／0002，修正版依赖已配套部署。

建议一并批准，避免以警告屏蔽掩盖未定义返回路径。它不证明真实驱动行为；其他剩余风险同上。
