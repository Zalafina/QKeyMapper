# Razer 虚拟键鼠驱动（PID 0306）

这是供 IbInput 使用的可选驱动包。QKeyMapper 不会自动安装、卸载或替换它。

## 已有 Razer 设备、Synapse 或其他 Razer 驱动的用户

请先在 QKeyMapper 的 **IbInput 设置**中选择 **Razer**，点击**连接检查**：
- 能够连接时，无需为了 IbInput 重新安装本包。
- 连接失败时，先查看错误和以下安装条件；失败不等于必须重装。
- 本包来自旧版 Nanoleaf，可能涉及与现有 Razer 软件共用的驱动组件。当前未验证它与 Synapse 4、实体 Razer 设备的完整共存效果，请勿直接卸载或替换正在使用的驱动。
- 如确需变更，请先保留原软件／驱动的恢复方法并停止相关输入程序。不要因为本机测试结果就认为所有 Synapse 或设备组合都适用。

已有运行记录包括 Windows 11 AMD64、没有实体 Razer 设备、G HUB 与这套独立驱动共存；另有用户在 Windows 10 x64 22H2 虚拟机中仅安装本套 Razer 驱动、未安装 G HUB，完成安装与连接检查，并在自动选择后端时通过 Q→T 的记事本映射验证。这些是各自所选范围的结果；系统重启后恢复及其他设备组合仍待验证。

## 运行条件

- 驱动文件为 **AMD64**，不支持 x86 操作系统或 ARM64。
- 本包仅面向 64 位 Windows 10／11，**不支持 Windows 7**。具体最低 Win10 构建号未单独验证，不从 INF 的 DriverVer 版本号推导。
- RazerDriver 目录仅包含在 **Qt6_x64、Qt5_x64** 发布包中，不包含在 Qt5_x86 包中。64 位 Win10／Win11 用户请选择合适的 x64 发布包。
- 管理工具使用 Windows 自带的 PowerShell 5.1。查看状态无需管理员；安装／移除需要由用户确认 UAC。
- 精确设备移除使用 PnPUtil /remove-device（Windows 10 2004／19041 起支持）。更早系统仅提示通过设备管理器手动处理，不回退删除驱动包。

## 手动管理

双击 **manage_driver.bat** 打开菜单：
1. **安装／修复驱动**：先确认确有需要，输入 INSTALL 后才注册驱动。遇到失败即停止并保留日志；不会先删除已有虚拟总线。
2. **移除虚拟设备（保留驱动包）**：仅按本包的精确虚拟硬件 ID、设备类和当前实例 ID 移除设备。驱动包保留在 DriverStore；这不是完整卸载。
3. **刷新状态**：查询本包虚拟总线、键盘及鼠标的设备状态。

install_driver.bat 和 uninstall_driver.bat 是对应菜单项的快捷入口。窗口会保留结果供查看，取消 UAC 或未确认 INSTALL 时不继续操作。出现“需要重启”时请方便时自行重启；本工具不自动重启。

安装或移除前请退出所有 QKeyMapper 实例。失败时保留窗口给出的 %TEMP%/QKeyMapper-RazerDriver-*.log，不要反复重试或自行删除驱动包、服务或过滤器。

## 控制台中文显示

如果中文显示为问号或方框，请分别在 **CMD 菜单窗口**和安装／移除时打开的**管理员 Windows PowerShell 窗口**中，右键标题栏 → **属性 → 字体**，选择 **NSimSun（新宋体）**等支持中文的字体。两个窗口的字体设置可能不同，只设置 CMD 字体不能保证 PowerShell 也正常显示。

用户已在 Windows 10 22H2 虚拟机验证：分别设置上述两个窗口的字体后，原版脚本即可正常显示中文，无需额外修改脚本输出编码、Windows 系统区域设置或启用全局 UTF-8 测试选项。PowerShell 脚本文件应保留 UTF-8 BOM，不要另存为 ANSI。若仍有问题，先关闭窗口并保留截图，不要在看不清提示时确认安装或移除。

## 在 QKeyMapper 确认

设备列表中可能出现以下设备：
- 键盘：HID\VID_1532&PID_0306&MI_00&Col01
- 鼠标：HID\VID_1532&PID_0306&MI_00&Col00

设备出现说明已枚举到虚拟设备；还应在 IbInput 设置选择 Razer 并执行连接检查。连接成功不代表所有映射已经过实际接收验证。

设备增减可能使 Interception 的设备编号／列表位置变化；依赖设备编号的既有配置需要按实际设备重新核对，不能只看列表顺序。
